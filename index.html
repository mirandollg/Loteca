Escudos dos times

O robô do GitHub busca os escudos no escudosfc.com.br e guarda no site. Se um clube aparecer com o escudo errado ou sem escudo, toque nele na aba Montar para escolher o certo. Seleções usam a bandeira do país.

Verificando…

Para remontar o índice de escudos na hora: no GitHub, abra Actions > Robô da Loteca > Run workflow e marque "Remontar o índice de escudos agora?". Ele também se remonta sozinho uma vez por semana.

Levar meus volantes para outro aparelho

Seus volantes e resultados ficam guardados neste navegador. Para passar para o celular ou o computador: copie aqui, mande para você mesmo (WhatsApp, e-mail) e cole no outro aparelho.

Cadastrar ou corrigir uma grade

Normalmente a grade vem sozinha da Caixa pelo robô. Use isto só se ela não aparecer: uma linha por jogo, na ordem do volante, no formato Mandante/UF x Visitante/UF.
